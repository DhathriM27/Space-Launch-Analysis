# 🚀 Space Launch Analysis Dashboard

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a Space Launch dataset using Python and Streamlit.

## Features

* Data Cleaning
* Missing Value Handling
* Duplicate Removal
* Time Series Analysis
* Mission Outcome Analysis
* Country-wise Analysis
* Interactive Dashboard

## Technologies Used

* Python
* Pandas
* Plotly
* Streamlit
* GitHub

## Dataset

The dataset contains information about space launches, mission outcomes, launch vehicles, customer countries, and launch dates.

## EDA Operations Performed

* Data preprocessing
* Missing value handling
* Duplicate removal
* Feature engineering
* Time series analysis
* Pivot table analysis
* Interactive visualizations

## Run the Project

```bash
streamlit run APP.py
```
